# helios-mcp

helios-mcp is a Python project. Behavioral genome for AI agents with drift detection and profile negotiation.

## Context retrieval

Start orientation with these indexed entry points: `src/helios_mcp/bootstrap.py`, `src/helios_mcp/cli.py`, `src/helios_mcp/server.py`, `src/helios_mcp/taxonomy.py`, `src/helios_mcp/distribution.py`, `src/helios_mcp/profile.py`, `src/helios_mcp/observer.py`, `src/helios_mcp/drift.py`. Use `code_nav` (modes: symbol, path, entries, outline, deps, dependents, wiki) before broad reads when the task is navigational.
